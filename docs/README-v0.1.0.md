# ProfileVault

本地优先、无需训练或模型服务的个人资料库与 Chrome / Edge 填表扩展。保存资料，主动扫描目标网页，逐项检查拟填值并确认；最后由你在网页检查和提交。界面为简体中文，识别中英文标准字段。

当前版本为本地评审候选版 0.1.0。源码、`dist/` 和 `release/profilevault-0.1.0.zip` 一并交付。验收证据及尚未完成的人工核验见 [验收报告](docs/ACCEPTANCE.md)，不能视为商店发布认证。

## 安装

1. 解压 `release/profilevault-0.1.0.zip` 到一个固定目录，或直接使用本项目的 `dist/`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展”，选择**直接包含 manifest.json 的目录**。
4. 在扩展菜单中固定 ProfileVault。打开目标网页后点击工具栏图标，即打开资料库窗口。

扩展不自动上架或发布，不要求账户。测试浏览器版本：Chrome 154.0.8037.98、Edge 155.0.4283.62（Windows）。最低 API 版本设为 Chrome 120；旧版本尚未实测。

## 使用

首次创建至少 12 个字符的主口令，允许空格、粘贴和长口令，不做静默 trim 或截断。**忘记主口令无法恢复**。创建档案，填写需要的资料后点击“保存资料”。没有预置的生产示例资料；测试夹具均为虚构数据。

左侧可新建、复制、设为默认或删除档案，最多 20 个。离开有未保存修改的编辑区会提示；删除需要确认。电话分国家呼叫码、本地号码和可选分机，号码、邮编保留字符串及前导零。出生日期默认折叠。

点击“网页填写”后核对目标 origin、网页标题和当前档案，再主动扫描。多表单、fieldset 或收货/账单分区必须先选择一个分区。检查每项拟填值、资料项、依据、规则分与风险，可以手动选择固定资料项或输入本次临时值。修正不修改资料库，也不记住站点映射。

只有高分、空白、普通、无冲突的 HTTPS 字段可能预选。出生日期、网页已有值、HTTP、autocomplete=off、checkbox/radio 均需要单独选择。已有值还需逐项批准覆盖；在预览后变化的网页值即使批准覆盖也会跳过。禁止字段没有手动绕过入口。

点击“填写已选 N 项”后，扩展只发送这 N 项批准值，逐项报告写入、跳过、失败、回退或页面变化。报告只代表两次检查时状态。**填写后，本网站即可读取所选信息；部分网站可能立即保存。** 扩展不主动提交、点击下一步、接受条款或订阅营销。

最近一批可在 2 分钟内撤销：仅尽力恢复仍为原节点、结构未变、值未变且填写后未编辑的控件。编辑过再改回也会跳过。撤销无法撤回网站已经读取或发送的数据。新扫描、新批次、锁定、关闭窗口、导航会清除撤销状态。

工具栏点击绑定当时的标签页，切换其他标签页不会改变目标。已有扩展窗口时再次点击只聚焦原窗口。需要换目标时，先关闭资料库窗口，再在新目标网页点击扩展。导航或节点重建后必须重新扫描，不恢复旧勾选或覆盖批准。

关闭或重载窗口即锁定；界面无操作默认 5 分钟后锁定，可选 1/5/15 分钟。网页活动不延长解锁。可以随时“立即锁定”。

“备份与安全”仅导出已保存、已校验的加密 `.profilevault.json`，文件名不包含档案名。导入最大 2 MiB，须输入备份口令，验证后预览档案数量和名称，再明确确认整库替换，不做合并。请先导出旧库；错误口令或损坏文件不会改动旧库。改口令需当前口令，原备份仍使用原口令，请导出新备份。

**卸载扩展或清理浏览器配置可能丢失全部资料**。备份需要自行保管；删除无法保证介质历史残留被擦除。

## 开发与复现

依赖固定版本并附 `package-lock.json`。实测 Node 24.19.0、npm 11.6.2。需要已安装 Chrome，E2E 用独立临时浏览器配置，通过 CDP 的 `Extensions.loadUnpacked` 与 `triggerAction` 加载真实扩展及触发真正 action，不 mock 扩展 API。

```powershell
npm ci
npm run dev
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
npm run test:e2e
npm run package
```

`dev` 监视构建产物；扩展仍从 dist 加载，改动后在扩展管理页重新加载。没有运行时开发服务器、CDN 或联网服务。修改 manifest、图标或首次入口后应重新执行 build。

Edge 自动化：

```powershell
$env:PV_BROWSER='msedge'
npm run test:e2e
Remove-Item Env:PV_BROWSER
```

测试入口需浏览器支持测试用 CDP Extensions 接口；较旧浏览器可设置 `PV_BROWSER=chromium` 并 `npx playwright install chromium`。`PV_EXECUTABLE` 可指定测试浏览器可执行文件，`PV_DIST` 可指定 ZIP 解压目录。测试浏览器启动参数只用于测试，不进入扩展包。

本次环境没有全局 npm，因此实际以项目内临时下载的固定 npm CLI 执行以上命令；`.tools/` 不参与构建和分发。正常安装 Node/npm 的机器不需要该目录。完整环境与验证记录见 [TESTING](docs/TESTING.md)。

## 权限与隐私

| 权限      | 用途                                                  |
| --------- | ----------------------------------------------------- |
| storage   | 持久化加密 envelope；session 中仅保存窗口与目标元数据 |
| activeTab | 用户点击工具栏后临时访问所选页面                      |
| scripting | 用户扫描时按需注入主文档 isolated 内容脚本            |

没有全站 host_permissions、静态 content_scripts、tabs、剪贴板或 downloads 权限，没有网页外部通信入口。没有模型、API、账户、云同步、遥测、远程字体或远程脚本。详见 [隐私说明](PRIVACY.md) 和 [安全说明](docs/SECURITY.md)。

加密采用 Web Crypto PBKDF2-HMAC-SHA-256（默认 600,000 次）与 AES-256-GCM，每次保存新 IV，密钥不可导出。具体参数、认证元数据、大小限制和威胁边界见安全文档。无法防护已控制操作系统的恶意软件、被篡改的扩展、弱口令离线破解或网站已收到的信息；JS 不保证内存立即物理擦除。

## 支持与限制

支持主文档中常见原生文本、email、tel、url、textarea、date、select、radio 和 checkbox。select 仅精确唯一匹配，radio 按 form owner、name、root 分组，不按位置选择。复选框和单选框用本次手动目标状态，不在档案中保存同意或业务状态。

原生 setter 与事件适配已在 React 19.1.1 的受控文本、select、onChange checkbox/radio 夹具中验证，包括实际用户提交处理器所读状态。checkbox/radio 除 input/change 外派发无默认激活行为的普通 click Event，以通知 React；不调用 `.click()`、不伪造 isTrusted、不点击提交按钮。依赖可信事件、复杂组件或页面特殊逻辑的控件仍可能拒绝或回退。

不支持 iframe、open/closed shadow DOM、contenteditable、canvas、自绘下拉框、复杂日期/地址联动组件、文件上传、教育/工作重复段落、跨步骤自动化、Firefox/Safari/移动端。受限浏览器页、扩展商店、PDF、file:// 不可扫描；测试夹具应通过本地 HTTP 使用。number 不用于当前固定个人字段，避免电话和邮编丢失前导零；search 不自动建议，明确搜索语义直接阻止。国家/地区目前支持字段目录中列出的 14 个代码，不猜测未知代码。

禁止保存或填写密码、安全问题、OTP/恢复码、支付凭据、政府证件标识、文件、签名和生物识别。协议、营销和声明控件排除。DOM 规则不是网站可信认证，恶意网站伪装字段仍需用户自行识别。

135 个可见字段的规则评估只代表该夹具，标注仍需独立人工复核。无默认站点映射或自定义脚本。更新前先备份；只接受 formatVersion/schemaVersion=1，未知版本拒绝，不静默迁移或覆盖。未来迁移必须独立校验、预览并保留旧加密备份。

问题报告请包含浏览器版本、错误码、虚构页面和重现步骤；不要上传真实资料、主口令、加密库或敏感截图。
