# 安全与隐私（0.2.0）

资料、附件与解析结果只在本地处理；运行时不需要网络模型或后端。浏览器只授予 storage、activeTab、scripting，无常驻全站读取权限。只有用户点击扩展并批准后才向当前目标页写入选定字段；网页自身可能监听字段变化或立即上传附件。

口令模式使用 PBKDF2 派生不可导出 AES-GCM 密钥，随机盐及 IV，并认证版本等元数据。解锁后的资料和密钥只在编辑窗口内存；关闭窗口或按设置闲置即锁定。本机免口令模式将随机解锁秘密持久化，与密文同处浏览器存储，可自动打开，不提供同等静态保密性。不要把免口令视为防止浏览器配置被复制的措施。

切换保护方式先验证必要口令，重新加密并原子更新密文和本机秘密。免口令导出必须设独立备份口令，备份不携带本机秘密；整库导入清除本机秘密，使用导入备份的口令。无账户、无口令找回；请保留加密备份。

旧 v1 库经认证后可读并在内存迁移；保存产生 v2。旧版不能读取 v2，因此升级前建议保留旧备份。资料库明文最多 6 MiB、导入文件最多 9 MiB，简历每份 2 MiB。存储失败和版本冲突不得清空原库。

PDF 解析使用随包附带的本地 worker，关闭 eval 和 worker 网络取数，不执行 PDF 动作，不渲染文档，限制页数、时间与文字长度。DOCX 只解压受限大小的 document.xml，拒绝实体与 DOCTYPE。解析候选必须由用户采用并保存；文本不作为指令执行。仍应仅导入可信文件。

页面内容和消息均不可信：字段规则拒绝密码、验证码、支付信息、同意条款等；预览绑定目标页面和扫描状态；写入前检查值、节点、导航及页面状态。自定义选择只点击已批准控件的受约束列表中唯一匹配项，不触发提交按钮。文件上传纳入预览批准且不能撤销；不承诺网站不会在变更时上传。

本扩展无法抵御已被控制的系统、浏览器、恶意扩展或已解锁页面读取已填资料。自动化验证不等同独立安全审计。
