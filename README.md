# ProfileVault

[简体中文](README.md) | [English](README.en.md)

**把常用求职资料存到本机，在申请实习或工作时批量填写网页。**

适用于桌面版 Chrome 和 Edge，当前版本 **0.2.1**。支持中英文资料、多段教育、实习／工作／项目经历，以及中英文简历附件。安装后独立运行，不需要 Codex、ChatGPT、API 密钥、付费模型或服务器。

> 第一次使用：下载安装包 → 加载扩展 → 建立资料 → 打开申请网页 → 扫描并批量填写。普通用户无需安装 Node.js 或运行代码。

## 1. 下载与安装

### 下载正确的文件

点击 **[下载 ProfileVault v0.2.1 安装包](https://github.com/JasmineLyf/-profilevault/raw/refs/heads/main/release/profilevault-0.2.1.zip)**。

这是可以直接加载的扩展包。GitHub 绿色 Code 按钮里的 Download ZIP 是源码，不能直接当扩展加载。

下载后解压到长期保留的文件夹，例如 `D:\Apps\ProfileVault`。打开后应该能看到 `manifest.json`，以及 `ui`、`content`、`background` 等子文件夹。

不要直接选择 ZIP 或压缩包预览。后面需要选择的是**解压后含 manifest.json 的文件夹**。安装后不要移动或删除它，浏览器会继续从这里读取扩展。

### Chrome 安装步骤

1. 地址栏输入 `chrome://extensions`，按回车。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择刚才解压出来、含 `manifest.json` 的文件夹。
5. 页面出现 ProfileVault 卡片，表示已加载。
6. 点击浏览器右上角的拼图图标，找到 ProfileVault，点击图钉，将它固定在工具栏。

### Edge 安装步骤

1. 地址栏输入 `edge://extensions`，按回车。
2. 打开“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择含 `manifest.json` 的文件夹。
4. 在工具栏的扩展菜单里找到 ProfileVault，选择在工具栏显示。

不同浏览器版本的按钮文字可能稍有区别。这是本地加载扩展，不是通过扩展商店安装。

## 2. 第一次打开：创建资料库

点击工具栏的 ProfileVault 图标，会打开独立的资料窗口。第一次使用显示“创建本地资料库”。在“保护方式”中选择一种：

| 方式       | 操作与日常使用                                                           | 适合的情况                   |
| ---------- | ------------------------------------------------------------------------ | ---------------------------- |
| 口令保护   | 设置并确认至少 12 个字符的主口令，点击“创建加密资料库”；以后打开需要解锁 | 希望为资料增加口令保护       |
| 本机免口令 | 选择“本机免口令”，点击“创建免口令资料库”；以后可直接打开                 | 独占使用的电脑，优先考虑方便 |

免口令模式会将随机解锁凭据与密文一起保存在浏览器配置中。能访问这份配置的人也可能直接打开资料，保护强度低于口令模式。

主口令不能通过邮箱或客服找回，请自行保管。

## 3. 建立你的资料档案

点击“创建第一个档案”。资料库是容器，档案是一套具体的求职资料；通常先建一份即可，以后可以按不同用途新建档案。

1. 在“档案名称”填写便于识别的名称，例如“我的求职资料”，用于扩展内部区分。
2. 填写姓名、邮箱、电话和地址等。没有的信息可以留空，不要编造。
3. 中文姓名旁边就是 English 字段；姓名、地址、单位等按中英文相邻排列，方便连续录入。
4. 电话国家呼叫码与本地号码分开填。例如中国手机的国家呼叫码填 `+86`，本地号码填手机号。邮箱、电话、国家代码和邮编等共用。
5. 点击“保存资料”，看到成功提示才表示已存入资料库。录入或解析完成后不要忘记保存。

**中英文需要分别填写，不会自动翻译。** 学校和公司英文名请使用其正式名称。选择英文填表时，对应英文内容未设置的字段可能无法填写。

### 教育经历

点击“＋ 添加教育经历 / Add education”，按实际情况添加本科、硕士、博士等记录。每条可填写中英文学校、专业、学历、起止年月和描述；不需要把每种学历都填一遍。

- “最高学历”与“当前学历”可以标记同一条，也可以分别标记不同记录。
- 按实际情况和申请表要求选择，扩展不会判断学位是否已经授予。
- 填表时默认优先使用当前学历，其次最高学历；只有一条记录时也可自动选用。预览中仍可切换。

### 实习、工作和项目经历

点击“＋ 添加实习／工作／项目经历”，选择类型，填写中英文单位或项目名称、职位、描述和起止年月；尚未结束的经历可标记当前状态。

有多条记录时，在填表预览中选择本次使用哪条；重复经历栏还可以为各字段选择对应记录。

## 4. 添加简历并自动解析

在资料编辑页找到简历区域：

1. 在“简历语言”选择中文或英文。
2. 点击“添加并解析简历”，选择对应语言的 PDF 或 DOCX 文件。
3. 等待本地解析完成，可展开“检查提取的全文”查看文本。
4. 查看“解析建议”：姓名、邮箱、网站等可点击“采用此项”，确认后替换对应资料内容。
5. 教育信息点击“添加为教育经历草稿”，经历信息点击“添加为经历草稿”。检查并修改生成的学校、单位、职位、日期等内容。电话候选需手动核对国家码后填入。
6. 点击“保存资料”。如有另一语言的简历，切换语言并重复操作。

**添加附件不等于解析结果已全部写入资料。** 原文件会保留供之后上传，解析候选需要采用或编辑后保存。

| 限制       | 说明                                                 |
| ---------- | ---------------------------------------------------- |
| 格式       | PDF、DOCX；不支持旧 DOC                              |
| 数量       | 每个档案中文、英文各一份；同语言添加新文件会替换附件 |
| 单份大小   | 最多 2 MiB                                           |
| PDF 页数   | 最多 30 页                                           |
| 提取文本   | 最多 60,000 字符                                     |
| 资料库总量 | 明文最多 6 MiB，包含附件内容                         |

解析使用本地文字和规则，不调用大模型。复杂排版可能拆分不准；图片型扫描 PDF 没有可提取文字，本版不含 OCR。如果提示文件已添加但解析失败，仍可保存附件、手动录入资料，并在填表时使用该附件。

## 5. 在招聘申请页批量填写

### 先打开申请表，再点击扩展

在浏览器打开岗位的**实际申请表**，让姓名、学校等输入框显示出来，再点击该网页上的 ProfileVault 工具栏图标。扩展会绑定点击时的网页。

在资料窗口选择档案，打开“网页填写”，点击“扫描当前目标网页”。**扫描仅识别表单，不会立即写入。**

### 选择本次填写的内容

扫描后显示“检查本次填写”：

- “填写语言 / Language”：中文申请选中文资料，英文申请选 English profile。
- “本次教育经历”：选择这次要使用的教育记录。
- “本次实习／工作／项目经历”：选择对应经历；多条记录时尤其需要确认。
- “表单分区”：可查看全部分区，也可切换到某一段。

切换语言或记录后，核对“拟填值”。**有资料且匹配明确的空字段会自动选中**，包含支持的下拉框和简历附件，不需要逐项勾选。

### 一次填写，再到网页检查

1. 确认网站、来源和拟填值正确；不想填写的项可取消勾选。
2. 点击底部“填写已选 N 项”。扩展批量尝试填写并显示结果；某项失败不代表其他项失败。
3. 回到申请网页检查实际内容，尤其是学校、学历、国家、城市、日期和附件。
4. 手动补齐网站额外要求的内容，最后由你自己提交申请。

已有内容不自动覆盖；需要在对应字段批准覆盖后再选择填写。普通文本可“撤销本次填写”，但已经被你再次编辑的字段不会强行还原。自定义下拉和附件没有扩展撤销，请直接在网站修改或移除。

### 下拉框如何填写

支持原生选择框，以及部分搜索式、滚动式自定义选择框。学历可识别 `PhD`、`Ph.D.`、`Doctor of Philosophy (Ph.D.)` 等等价名称，不把医学或法学博士当成相同学位。

国家和常见城市支持中英文别名，例如“中国 / China”“北京市 / Beijing”；搜索无结果时会尝试另一语言。未收录城市按你保存的对应语言内容匹配。

只有找到唯一、可用的匹配项才选择。不保证适配所有自绘控件、远程搜索或虚拟列表；没有选上时请手动选择，不要为了匹配而把资料改成错误内容。

### 多段教育或经历

先在网站手动点击 Add another／添加经历，显示新的输入栏，再重新扫描。在预览里为各字段选择对应记录，核对后填写。扩展不会自动新增网站行。

### 上传简历

保存附件后，扩展根据“填写语言”使用对应文件，附加到明确的 Resume／CV 上传框，并检查网站接受的格式。不会把简历填到 Cover letter（求职信）框。

网站可能在选择文件后立即上传，**即使未点击提交，也可能已经收到附件和字段内容**。只在信任的网站使用，并在网页检查文件名。

## 6. 备份与换电脑

在“备份与安全”点击“导出加密备份”，保管生成的 JSON 文件。免口令模式也需要设置并确认独立备份口令；备份不包含本机免口令凭据。

换电脑或换浏览器时，先安装扩展，通过“从加密备份恢复”或备份页的导入功能恢复。输入备份口令并确认后会**整库替换，不是合并**。导入文件上限 9 MiB。

Chrome、Edge 和不同浏览器配置的资料不自动同步。卸载扩展、清理存储或删除浏览器配置可能丢失资料，请定期备份。

## 7. 常见问题

**找不到扩展图标？** 打开浏览器右上角的拼图／扩展菜单并固定 ProfileVault；菜单里也没有时，到扩展管理页确认已加载并启用。

**提示找不到 manifest.json？** 通常选了 ZIP、源码目录或多套一层的父文件夹。找到解压后的 manifest.json，选择它所在的文件夹。

**保存后仍显示可填写 0 项？** 检查档案是否保存、是否选对语言、该语言是否有内容、教育／经历是否选好，以及网页是否已经有值。含糊或未识别字段不会自动选中，可检查来源映射或手填。

**扫描失败、目标失效或预览对应了另一页？** 关闭资料窗口，在正确申请页重新点击扩展，再扫描。网页导航、刷新或动态新增输入栏后，也需重新扫描。

**学校、城市、学历选不上？** 检查正式名称、语言及记录。网站没有对应选项、候选不唯一或控件不受支持时，请手动选。

**解析出的公司、岗位或日期不对？** 解析结果是草稿，改好再保存。扫描 PDF 可先用其他工具转成带文字的文档，或直接手动录入。

**证件、验证码、同意条款怎么办？** 在网站手动完成。扩展不填密码、验证码、支付信息等被禁字段，不点击下一步、同意条款或最终提交。

**某些页面无法使用？** 本版面向普通网页主文档，不支持浏览器内部页、扩展商店、浏览器 PDF 查看器、本地 file:// 页面，以及部分 iframe、封闭 shadow DOM 或特殊控件。

**资料会发到云端吗？** 扩展没有后端、模型 API 或云同步，资料与解析留在本机。但批准填入网页后，该网站即可读取或上传这些内容。见[隐私说明](PRIVACY.md)。

## 给开发者：源码构建

普通用户使用前面的安装包即可。开发需要 Node.js 22.13+；验证环境为 Node.js 24。

```sh
git clone https://github.com/JasmineLyf/-profilevault.git profilevault
cd profilevault
npm ci
npm run build
```

加载生成的 dist 文件夹。`npm run package` 生成安装 ZIP。技术资料：[测试说明](docs/TESTING.md)、[验收记录](docs/ACCEPTANCE.md)、[安全说明](docs/SECURITY.md)、[兼容性](docs/COMPATIBILITY.md)。
