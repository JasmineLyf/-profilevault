# ProfileVault

[简体中文](README.md) | [English](README.en.md)

当前版本：0.2.1

本地优先的 Chrome / Edge 个人资料库与填表扩展。无需服务器、Codex、模型 API 或账户；安装后独立运行。默认口令加密，也可选本机免口令。

## 更新已有安装

1. 先在旧版导出加密备份。
2. 将新版安装包解压覆盖原安装目录，或在源码目录运行 npm run build；进入 chrome://extensions 或 edge://extensions，点击 ProfileVault 卡片的刷新按钮。
3. 关闭并重新打开扩展窗口，刷新目标招聘网页，然后重新扫描。不要卸载扩展，卸载可能清除资料。
4. 旧资料用原口令打开；保存后升级为 v2 格式，旧版不能读取新格式。请保留升级前的备份。

新安装：下载 [v0.2.1 安装包](release/profilevault-0.2.1.zip)，解压到固定文件夹。打开浏览器扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选择解压后含 manifest.json 的文件夹（源码构建则选 dist）。ZIP 必须先解压到固定目录，再加载其中含 manifest.json 的目录。

## 建立资料

- 建库时选择口令保护或本机免口令。已有库可在“备份与安全”验证原口令后改为免口令，也可重新启用口令。
- 本机免口令把随机解锁密钥与密文一起存到浏览器本地；能复制浏览器资料的人可能读取它，保护强度低于口令模式。免口令导出仍需设置独立备份口令。
- 中文资料和英文资料分别维护，不自动翻译。电话、邮箱等共用。
- 教育经历可添加多条本硕博等记录，分别标记最高学历和当前学历；另可添加实习、工作、项目经历。填表预览中选择语言及对应经历。

## 导入并自动解析简历

在资料编辑页的简历区域分别添加中文、英文 PDF 或 DOCX，每份最多 2 MiB。扩展在本地提取文字并生成姓名、邮箱、电话、网站、教育和经历候选；点击采用或添加草稿后，核对并修改，再保存资料。原文件同时保留，用于之后附加到招聘网页。

解析使用规则，不调用大模型；复杂排版可能需要手动拆分学校、公司和岗位。扫描 PDF 无 OCR，旧 DOC 不支持。PDF 最多 30 页，提取文字最多 60,000 字符。每种语言一份简历，整个资料库明文上限 6 MiB，备份文件上限 9 MiB。

## 填写招聘网页

1. 打开申请表，点击浏览器工具栏的 ProfileVault 图标。
2. 解锁后选择资料、语言和教育/经历记录，扫描当前页面。
3. 在预览中逐项核对来源、值及勾选状态，然后批准填写。
4. 有资料且匹配明确的空字段默认自动选中，包括下拉框和简历附件；一次点击“填写已选”即可批量填写，无需逐项勾选。已有值不自动覆盖，含糊的匹配仍需确认。支持原生选择框，以及具有可识别语义的搜索式、滚动式 combobox（包括测试过的 React Select）。博士支持 PhD、Ph.D. 与 Doctor of Philosophy (Ph.D.) 等等价名称，避免与医学、法学博士混淆。只在找到唯一准确选项时选择；没有匹配项会报告失败。
5. 多段教育先在网站点击 Add another，再重新扫描，给每一段选择对应经历。扩展不自动新增网站行。
6. 简历仅附加到明确的 Resume / CV 上传框，文件格式须符合网站要求；网站可能在选择文件时立即上传。自定义下拉和附件不提供扩展撤销，请在网页核对或修改。普通文本仍支持条件撤销。

扩展不会点击提交、下一步或同意条款，不填写密码、验证码、付款信息等敏感字段。无法保证适配所有自绘、跨域或虚拟化控件；遇到无法识别的控件请手填。

## 开发和验证

需要 Node.js 22.13+（本项目验证环境为 Node.js 24）。

```sh
git clone https://github.com/JasmineLyf/-profilevault.git profilevault
cd profilevault
npm ci
npm run build
```

产物为 dist。npm run package 生成 release/profilevault-0.2.1.zip。命令、结果和限制见 docs/TESTING.md、docs/ACCEPTANCE.md；安全说明见 docs/SECURITY.md。

0.2.1：中英文姓名、地址、单位字段已相邻排列。国家与常见城市支持中英文下拉别名（如 中国/China、北京市/Beijing），搜索无结果会尝试另一语言；未收录城市仍按所填语言精确匹配，请维护对应英文资料。
